# Web Tool Submission Instructions

## VaxiJen 2.0 Submission
**URL**: http://www.ddg-pharmfac.net/vaxijen/VaxiJen/VaxiJen.html

**Steps**:
1. Select 'Virus' as target organism
2. Set threshold to 0.4
3. Upload each FASTA file from `vaxijen/` folder
4. Record antigenicity scores in validation spreadsheet

## AllerTop 2.0 Submission
**URL**: https://www.ddg-pharmfac.net/AllerTOP/

**Steps**:
1. Paste sequence from each `.txt` file in `allertop/` folder
2. Submit for allergenicity prediction
3. Record results (Allergen/Non-allergen) in spreadsheet

## ProtParam Analysis
**URL**: https://web.expasy.org/protparam/

**Steps**:
1. Paste each construct sequence
2. Analyze physicochemical properties
3. Compare with automated analysis results
