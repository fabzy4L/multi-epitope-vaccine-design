## EPITOPE PREDICTION SETUP

### MHC-I (CD8+ T-cells)
   Target: Cytotoxic T lymphocyte responses

   IEDB Parameters:
   - Method: NetMHCpan EL 4.1
   - Peptide Length: 9-mers (standard)
   - Alleles: HLA-A*02:01, HLA-A*01:01, HLA-B*07:02, HLA-B*35:01
   - Threshold: IC50 ≤ 50 nM OR percentile rank ≤ 0.5

   Population Coverage:
   - HLA-A*02:01: ~45% Caucasian, ~12% African, ~40% Asian
   - HLA-A*01:01: ~25% Caucasian, ~10% African, ~1% Asian
   - HLA-B*07:02: ~20% Caucasian, ~15% African, ~5% Asian
   - Combined: >70% global population coverage

### MHC-II (CD4+ T-cells)
   Target: Helper T cell responses and antibody induction

   IEDB Parameters:
   - Method: NetMHCIIpan EL 4.1
   - Peptide Length: 15-mers (standard)
   - Alleles: HLA-DRB1*01:01, HLA-DRB1*03:01, HLA-DRB1*07:01, HLA-DRB1*15:01
   - Threshold: Percentile rank ≤ 10.0

   Population Coverage:
   - HLA-DRB1*01:01: ~20% Caucasian, ~15% African, ~10% Asian
   - HLA-DRB1*03:01: ~25% Caucasian, ~20% African, ~15% Asian
   - HLA-DRB1*07:01: ~25% Caucasian, ~15% African, ~10% Asian
   - Combined: >60% global population coverage

## FUNCTIONAL DOMAINS IN S1 REGION

### Signal Peptide (residues 1-13)
   - Remove from epitope prediction (cleaved in mature protein)
   - Not present in secreted spike protein

### N-Terminal Domain (NTD, residues 14-290)
   - Contains neutralizing antibody epitopes
   - Include in B-cell epitope prediction
   - Moderate priority for T-cell epitopes

### Receptor Binding Domain (RBD, residues 319-541)
   - PRIMARY TARGET for neutralizing antibodies
   - Highest priority for epitope prediction
   - Key residues: 417, 484, 501 (variant hotspots)

### Subdomain 1 (residues 290-319)
   - Linker region between NTD and RBD
   - Lower priority for epitope selection

### Subdomain 2 (residues 541-685)
   - Contains S1/S2 cleavage site (furin site)
   - Important for viral entry mechanism
   - Moderate priority for T-cell epitopes

## QUALITY CONTROL CHECKPOINTS

### Before IEDB Submission:
   1. ✅ Verify sequence source organism (Severe acute respiratory syndrome coronavirus 2)
   2. ✅ Confirm sequence length (685 aa for S1 domain)
   3. ✅ Check for non-standard amino acids or ambiguities
   4. ✅ Validate FASTA format (single line header, wrapped sequence)

### After Epitope Prediction:
   1. ✅ Filter by binding affinity thresholds (IC50 ≤ 50 nM for MHC-I)
   2. ✅ Check for self-similarity to human proteome (avoid autoimmunity)
   3. ✅ Prioritize epitopes from functionally important regions (RBD > NTD > other)
   4. ✅ Consider variant stability (avoid sites with high mutation rates)

## COMMON PITFALLS TO AVOID

❌ Using wrong organism sequences (e.g., D. medinensis instead of SARS-CoV-2)
❌ Submitting full proteome datasets to web servers (causes timeouts)
❌ Ignoring HLA population frequencies (reduces vaccine efficacy)
❌ Selecting epitopes from non-conserved regions (variant escape)
❌ Overlooking human homology screening (autoimmune risk)
❌ Choosing epitopes solely on binding affinity (ignore functional context)

## RECOMMENDED WORKFLOW

Step 1: Input Selection
   → Use sars_cov2_s1_domain.fasta (685 aa, single sequence)

Step 2: MHC-I Prediction
   → Submit to IEDB with 4 common HLA-A/B alleles, 9-mer peptides

Step 3: MHC-II Prediction
   → Submit to IEDB with 4 common HLA-DRB1 alleles, 15-mer peptides

Step 4: Results Integration
   → Combine with existing B-cell epitope data
   → Apply scoring criteria from Stage 03 (antigenicity, allergenicity)

Step 5: Functional Annotation
   → Map epitopes to functional domains (RBD, NTD, cleavage sites)
   → Prioritize based on neutralization relevance
